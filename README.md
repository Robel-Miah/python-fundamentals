## Getting Started

### Prerequisites

- Python 3
- Git
- Visual Studio Code (or another Python-compatible IDE)

### Clone the Repository

```bash
git clone https://github.com/Robel-Miah/python-fundamentals.git
cd python-fundamentals
```

### Run a Python Program

```bash
python3 01-introduction/main.py
```
